Passo a Passo: Commit 1 (Treinador e Itens)
No terminal (lembra-te de colar usando botão direito do rato -> Paste), executa um comando de cada vez:

Bash
# 1. Garante que partes da branch development limpa
git checkout development

# 2. Cria a branch para treinador e itens
git checkout -b feat/treinador-e-itens

# 3. Adiciona apenas os 3 ficheiros desta entrega
git add src/main/java/br/com/pokesal/enums/TipoItem.java src/main/java/br/com/pokesal/resultado/Item.java src/main/java/br/com/pokesal/resultado/Treinador.java

# 4. Faz o commit
git commit -m "feat(modelo): adiciona treinador, item e tipo de item"

# 5. Envia para o GitHub
git push -u origin feat/treinador-e-itens
(Nota: se tiveres movido Item.java e Treinador.java para a pasta modelo, troca resultado por modelo no comando git add acima).

como fazer o clone de um negocio no git

Para clonar um repositório no Git, use o comando git clone seguido do link do projeto:

Copie a URL do repositório na plataforma onde ele está hospedado (GitHub, GitLab, Bitbucket, etc.), clicando no botão Code (ou Clonar) e copiando o endereço HTTPS ou SSH.

Abra o terminal (Prompt de Comando, PowerShell, Terminal ou Git Bash) e navegue até a pasta onde deseja salvar o projeto:

Bash
cd caminho/da/sua/pasta
Execute o comando de clone:

Bash
git clone https://github.com/usuario/nome-do-repositorio.git
Entre na pasta criada para começar a trabalhar nos arquivos:

Bash
cd nome-do-repositorio
Variações úteis
Clonar com outro nome de pasta:

Bash
git clone https://github.com/usuario/nome-do-repositorio.git novo-nome-da-pasta
Clonar apenas uma branch específica:

Bash
git clone -b nome-da-branch https://github.com/usuario/nome-do-repositorio.git
