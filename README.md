# PokeSAL

Simulador de torneios eliminatórios de batalhas por turnos no terminal. Os treinadores escolhem Pokésals e disputam partidas com precisão, críticos, elementos, itens, status e terreno até a definição do campeão.

## Principais funcionalidades

- Torneios com 4 ou 8 treinadores.
- Seis Pokésals iniciais e três golpes por Pokésal.
- Batalhas por turnos com itens, efeitos de status e terrenos.
- Histórico dos resultados em memória.

## Tecnologias

- Java 21
- Maven
- JUnit 5
- Mockito

## Como executar

Com JDK 21 e Maven instalados:

```bash
mvn compile
java -cp target/classes br.com.pokesal.Main
```
